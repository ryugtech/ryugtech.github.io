PLECT GAMES

정적 사이트입니다. index.html을 브라우저에서 열거나 프로젝트 폴더에서
python -m http.server를 실행해 확인할 수 있습니다.

- index.html에는 게임, 스튜디오, 문의 정보가 있습니다.
- styles.css에는 레이아웃, 색상, 반응형 스타일이 있습니다.
- script.js는 푸터 연도를 현재 연도로 표시합니다.
- privacy.html에는 Pocket Island 개인정보 처리방침이 있습니다.
- app-ads.txt는 GitHub Pages 루트에서 제공됩니다.
- assets/에는 브랜드 아이콘, 게임 이미지, 콘셉트 아트, 폰트가 있습니다.

GitHub Pages: https://ryugtech.github.io/
